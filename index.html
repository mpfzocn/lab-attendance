How to Add New Students:
  1. Scroll down to the Admin Tools section (you are here).
  2. Under Add New Student, enter the details:
    • Student ID: Enter the new student's ID (e.g., 16207119).
    • Student Name: Enter the student's full name (e.g., Md. Mazaharul Islam).
  3. Click the Add Student button. You will see a green confirmation message indicating the student has been added successfully.
